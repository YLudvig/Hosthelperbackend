Thesis project for Java

Backend to my Hosthelper (tempname) application

This backend uses: 
- Java
- Spring Boot
- PostgreSQL (Very popular open source SQL dialect)
- Docker 

The purpose of this backend is to allow users to have a locally stored backend database to store their information about their remotes on their own machine. 

Docker is used to create a PostgreSQL database in docker for the backend to connect to.
